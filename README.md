# Datapace skills

Agent skills from [Datapace](https://datapace.ai) for coding agents.

## assess

`/assess` walks you through the Datapace Cloud Self-Assessment: your coding agent runs the open-source [`datapace-collector`](https://pypi.org/project/datapace-collector/) against your own cloud account, and your credentials never leave your machine.

```bash
npx skills add datapace-ai/skills
```

Then type `/assess` in Claude Code, or `$assess` in Codex.
